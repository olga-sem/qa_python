# qa_python
Итоговый проект 4 спринта. Для проверки приложения BooksCollector были проведен>
1) Добавление двух книг в словарь
2) Книга с названием, в котором больше 40 символов, не добавляется в словарь
3) Повторное добавление книги в словарь невозможно
4) Установление книге жанра из предоставленного списка с жанрами
5) Установление книге жанра невозможно, если этого жанра нет в предоставленном >
6) Получение жанра по названию книги
7) Получение названий книг по определённому жанру
8) Получение словаря с добавленными книгами
9) Получение книг для детей, жанр которых не относится к 18+
10) Добавление книги в список избранных книг
11) Удаление книги из списка избранных
12) Получение списка избранных книг
